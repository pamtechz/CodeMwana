# CodeMwana

CodeMwana is a responsive, database-backed web application that teaches children basic programming skills and concepts.

This repository contains the complete ICT4410 Question 11 project, including the PHP application, database schemas, sample learning content, teacher and administrator dashboards, deployment instructions, tests, diagrams, and the research project report.

## Core features

- Learner registration and secure authentication
- Structured lessons and quizzes
- MwanaCode beginner programming interpreter
- Turtle graphics coding playground
- Saved learner projects
- Progress, points, badges, and leaderboard
- Teacher and administrator dashboards
- MySQL and SQLite support
- Responsive and low-bandwidth interface
- Progressive Web App support

## Requirements

- PHP 8.1 or later
- MySQL/MariaDB or SQLite
- Apache with `mod_rewrite` recommended

See `docs/DEPLOYMENT.md` for installation and hosting instructions.
